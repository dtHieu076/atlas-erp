K3s Setup Guide

*Master node
Step 1: Install K3s Server
Run the following command on your Ubuntu Master Node:
curl -sfL https://get.k3s.io | sh -
This script automates the download and configuration of K3s as a system service.

Step 2: Verify the Installation
Check if your node is up and running:
sudo kubectl get nodes

Step 3: Retrieve the Node Token
To join additional Worker Nodes to the cluster, you will need the token from the Master Node:
sudo cat /var/lib/rancher/k3s/server/node-token
